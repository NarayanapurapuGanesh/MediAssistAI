# MediAssist AI 🏥🤖

MediAssist AI is an intelligent health monitoring and medicine reminder application. It uses a **Flutter** mobile application for a beautiful cross-platform frontend and a **Python FastAPI** backend powered by **Google Gemini AI** for smart health alerts and insights. 

## 🏗️ Architecture

- **Frontend**: Flutter (Dart) - Cross-platform mobile app.
- **Backend**: FastAPI (Python) - High-performance async REST API.
- **Database**: SQLite - Lightweight, file-based SQL database (via SQLAlchemy ORM).
- **AI Engine**: Google Gemini AI - Generates health insights and alerts based on user data.
- **Authentication**: JWT (JSON Web Tokens) for secure session management.

## ✨ Features
- **User Authentication**: Secure login and registration.
- **Medication Tracking**: Log medications, schedules, and daily intake records.
- **Health Measurements**: Track vital signs and health metrics over time.
- **Routines**: Manage daily health routines.
- **AI Health Alerts**: Get intelligent alerts and suggestions generated by Google Gemini AI.

## 🚀 Getting Started

Follow these instructions to get the project up and running on your local machine.

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.12+ recommended)
- [Python](https://www.python.org/downloads/) (v3.12+ recommended)
- [Git](https://git-scm.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/NarayanapurapuGanesh/MediAssistAI.git
cd MediAssistAI
```

### 2. Backend Setup (FastAPI)

1. **Navigate to the backend directory:**
   ```bash
   cd backend
   ```
2. **Set up Environment Variables:**
   Copy the example environment file and add your secret keys.
   ```bash
   cp .env.example .env
   ```
   *Open `.env` and paste your actual **Gemini API Key** (get one from [Google AI Studio](https://aistudio.google.com/app/apikey)) and a **Secret Key** for JWT.*

3. **Create a Virtual Environment:**
   ```bash
   python -m venv venv
   ```
4. **Activate the Virtual Environment:**
   - **Windows PowerShell:** `.\venv\Scripts\Activate.ps1`
   - **Mac/Linux:** `source venv/bin/activate`
5. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
6. **Initialize the Database (SQLite):**
   Run the seeding script to create the local `mediassist.db` file and populate it with mock data:
   ```bash
   python seed_mock_data.py
   ```
7. **Run the Backend Server:**
   ```bash
   uvicorn main:app --reload
   # Note: If testing on a physical device over Wi-Fi, run: uvicorn main:app --reload --host 0.0.0.0
   ```
   The API will be available at `http://127.0.0.1:8000`. You can view the automatic interactive API documentation at `http://127.0.0.1:8000/docs`.

### 3. Frontend Setup (Flutter)

1. **Navigate to the mobile directory (in a new terminal):**
   ```bash
   cd mobile
   ```
2. **Install Flutter Dependencies:**
   ```bash
   flutter pub get
   ```
3. **Configure API Endpoint:**
   By default, the app is configured to talk to `127.0.0.1:8000` (works out of the box for Windows Desktop). 
   - If using an **Android Emulator**, open `lib/services/api_service.dart` and change the IP to `10.0.2.2`.
   - If using a **Physical Device (USB)**, run `adb reverse tcp:8000 tcp:8000` in your terminal.
   - If testing over **Wi-Fi**, change the IP in `api_service.dart` to your PC's local network IP (e.g., `192.168.1.6`).
4. **Run the App:**
   ```bash
   flutter run
   ```
